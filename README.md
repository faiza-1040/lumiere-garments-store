# Garments Store – Full‑Stack eCommerce

This repository contains a **modern, premium, fully‑responsive** eCommerce application for Men, Women, and Kids fashion.

## Folder layout
```
garments-store/
│
├─ backend/          # Node/Express API
│   └─ src/          # source code (models, routes, controllers…)
│
└─ frontend/         # Next.js (React) UI
    └─ src/          # pages, components, store, utils
```

The project is deliberately **not initialised as a Git repository** – you can add Git later if you wish.

## Getting started
1. Open two terminals.
2. **Backend**
   ```bash
   cd backend
   npm install
   npm run dev   # starts Express on http://localhost:5000
   ```
3. **Frontend**
   ```bash
   cd ../frontend
   npm install
   npm run dev   # starts Next.js on http://localhost:3000
   ```

Feel free to explore the code in `backend/src` and `frontend/src`.
