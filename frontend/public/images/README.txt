HOW TO ADD IMAGES:
1. Drop your image files (like 'hero.jpg' or 'shirt.png') into this folder.
2. In your Next.js code, you can display them by starting the path with '/images/'. 

Example:
If you put a file named "model.jpg" in this folder, you can use it in the code like this:
<Image src="/images/model.jpg" alt="Model" width={500} height={500} />
OR
<img src="/images/model.jpg" alt="Model" />
